## 📌 1. عن المنصة

منصة **«حلقة وصل»** هي مبادرة رقمية أكاديمية متكاملة تابعة لـ **المعهد العالي لنظم التجارة الإلكترونية بسوهاج**، تهدف إلى ردم الفجوة بين المحتوى الدراسي واستيعاب الطلاب من خلال:
1. إتاحة المحاضرات المعتمدة والملخصات العلمية المركزة بصيغة PDF قابلة للعرض والتنزيل الفوري.
2. بنوك أسئلة واختبارات تفاعلية حقيقية مستخرجة حرفياً من ملفات وتدريبات الدكاترة مع حساب دقيق للدرجات وتفسير أكاديمي لكل سؤال.
3. حفظ النتائج في سجل مركزي بـ Google Sheets لإتاحة لوحات تحليلية للدكاترة والإدارة لمتابعة مستوى الطلاب.
4. مساعد تعليمي ذكي مدمج يعمل بدون إنترنت وخالٍ تماماً من التكلفة، مع إمكانية الربط الخارجي بنماذج الذكاء الاصطناعي.

## 🚀 4. دليل النشر المجاني على GitHub Pages (خطوة بخطوة)

لا تحتاج إلى تثبيت برامج برمجية على جهازك، يمكنك النشر مباشرة من المتصفح في 3 دقائق:

### الخطوة 1: إنشاء مستودع على GitHub
1. سجّل الدخول إلى موقع [GitHub](https://github.com).
2. اضغط على زر **New** لإنشاء مستودع جديد (Repository).
3. اختر اسماً للمستودع (مثال: `halqa-wasl` أو `quick-tesla`).
4. تأكد من تحديد نوع المستودع كـ **Public** (عام) ليعمل النشر المجاني.
5. اضغط **Create repository**.

### الخطوة 2: رفع ملفات المنصة
1. داخل صفحة المستودع الجديد، اضغط على زر **Add file** ثم **Upload files**.
2. اسحب وأفلت الملفات التالية من مجلد المشروع:
   - `index.html` (الملف الأساسي في المجلد الرئيسي)
   - `style.css`
   - `app.js`
   - `data.js`
   - `Code.gs`
   - مجلد `assets` بالكامل (بما يحتويه من صور وملفات PDF).
3. اضغط زر **Commit changes** الأخضر أسفل الصفحة.

### الخطوة 3: تفعيل استضافة GitHub Pages
1. ادخل على تبويب **Settings** (الإعدادات) في مستودعك.
2. من القائمة الجانبية اليسرى اضغط على **Pages**.
3. تحت قسم **Build and deployment > Branch**:
   - اختر الفرع: `main` (أو `master`).
   - اختر المجلد: `/ (root)`.
4. اضغط زر **Save**.
5. انتظر دقيقة واحدة، ثم أعد تحديث الصفحة؛ سيظهر لك الرابط الحي في مستطيل ملون بالأعلى:
   ```
   Your site is live at https://<username>.github.io/<repository-name>/
   ```
   **مبروك! موقعك الآن متاح عالمياً لكل الطلاب والدكاترة بلينك رسمي دائم ومجاني.**

## 📊 5. دليل ربط السجل المركزي (Google Sheets + Apps Script)

لحفظ درجات ومحاولات جميع الطلاب مركزياً في جدول إكسل سحابي خاص بإدارة المعهد دون أي تكلفة:

1. افتح [Google Sheets](https://sheets.google.com) وأنشئ جدولاً جديداً باسم: **سجل نتائج منصة حلقة وصل**.
2. من القائمة العلوية اضغط: **الإضافات (Extensions)** > **Apps Script**.
3. احذف أي كود مكتوب داخل نافذة المحرر.
4. افتح ملف `Code.gs` الموجود في المشروع وانسخ محتواه بالكامل والصقه في المحرر، ثم اضغط حفظ (أيقونة القرص أو `Ctrl + S`).
5. اضغط على زر **Deploy (نشر)** الأزرق أعلى اليمين > اختر **New deployment (نشر جديد)**.
6. اضغط على أيقونة الترس بجانب "Select type" واختر **Web app (تطبيق ويب)**.
7. املأ الإعدادات بدقة كالتالي:
   - **Description:** استلام نتائج حلقة وصل.
   - **Execute as:** `Me (حسابك الشخصي)`.
   - **Who has access:** `Anyone (أي شخص)` — **(هذا الخيار ضروري حتى يستطيع موقع الطالب إرسال درجته دون طلب تسجيل دخول Google)**.
8. اضغط **Deploy**، ثم امنح الصلاحيات المطلوبة لحسابك (Authorize access).
9. انسخ رابط تطبيق الويب الناتج (ينتهي بـ `/exec`).
10. افتح موقع المنصة، ثم اضغط على صفحة **المساعد الذكي** > زر **إعدادات الربط** (أو افتح لوحة التحكم) والصق الرابط هناك، وسيتم حفظ كافة نتائج الطلاب في الجدول تلقائياً من تلك اللحظة!

> **💡 بديل فوري بدون ربط سحابي:** إذا لم تقم بالربط بعد، المنصة مجهزة تلقائياً بنظام حفظ محلي ذكي، مع زر يتيح للطالب أو الدكتور **تنزيل تقرير النتيجة بصيغة Excel / CSV** بنقرة واحدة، دون فقدان أي درجات.

## 🤖 6. المساعد التعليمي الذكي («مساعد حلقة وصل»)

تم تزويد المنصة بمساعد تعليمي ذكي ثنائي النواة:
1. **الوضع المحلي الفوري (مفعّل تلقائياً):**
   - يعمل 100% دون الحاجة إلى إنترنت خارجي أو مفاتيح API أو فوترة مالية.
   - مدرب على مفاهيم ومصطلحات محاضرات الفرقة الثانية الرسمية (تعريف التحليل، أدوار محلل الأعمال، أهداف اللوجستيات، وسلسلة الإمداد، وحسابات قائمة الدخل والمركز المالي).
   - يقترح أسئلة تدريبية سريعة للطالب ويشرح الإجابات النموذجية.
2. **وضع الربط الخارجي بـ Gemini API (اختياري):**
   - يمكن تفعيله من واجهة الإعدادات بإدخال مفتاح API في المتصفح المحلي فقط.
   - **حماية تامة للخصوصية:** لا يتم إرسال أسماء الطلاب أو درجاتهم أو أي بيانات تعريفية إلى نموذج الذكاء الاصطناعي، ولا يتم تخزين أي مفاتيح في كود الموقع المنشور للعامة.
